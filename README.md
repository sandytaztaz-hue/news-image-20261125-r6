# Sum 25 — Round 6: Wednesday 25 November 2026 in one image

A dense one-page broadsheet summing up Wednesday 25 November 2026: 50 dated stories,
3 drawn hero scenes (US tariffs on 14 economies, the Kospi -6.2% AI sell-off, Pakistan's
first astronaut docking at Tiangong), 12 medium cards with data chips, a 35-story brief
list, an IN NUMBERS strip, a UTC timeline, a dotted world map with numbered pins, a
TOMORROW box and a DATE CHECK strip. Every story was first reported on Wednesday
25 November 2026; earlier-day stories are listed as left out. Built with the live
top-5 formula: hero hierarchy first, true region and field counts, status pills
throughout.

## Run it

```sh
python3 render.py && MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`render.py` draws the 1024x1024 broadsheet with Pillow (build time only) and writes
`entry.png`; `main.py` is stdlib-only and copies it byte-identical to the output
directory. Rendering is deterministic: three runs produce identical bytes.
